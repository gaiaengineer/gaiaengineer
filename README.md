### What I build here

Small, practical tools I use in real work, mostly Claude skills and data utilities. They share a few rules: a human approves every step, no claim about a text without a quote from it, and every tool says plainly what it can't do.

| Project | What it does |
|---|---|
| [scout-skill](https://github.com/gaiaengineer/scout-skill) | Agentic outreach pipeline for Claude Code: discover → research → personalize → send, with Google Sheets and Smartlead integrations |
| [manuscript-triage](https://github.com/gaiaengineer/manuscript-triage) | Claude skill that reads book submissions and reports craft metrics, story structure and editing burden, with no score and no claim without a quote |
| [book-appraisal](https://github.com/gaiaengineer/book-appraisal) | Claude skill that compares a manuscript with a quoted, sourced corpus of recent bestsellers, and says plainly what the score can't see |
| [mini-analytics](https://github.com/gaiaengineer/mini-analytics) | Lightweight Metabase alternative: CSV exports in, static dashboards out, every chart backed by plain SQL (DuckDB, Plotly) |
| [mini-web-editor](https://github.com/gaiaengineer/mini-web-editor) | Book editor that runs entirely in the browser: Word import, phone and tablet preview, and EPUB export that passes EPUBCheck with 0 errors (ProseMirror, Next.js) |
